CSS Transformation

CSS Tansformation allows us to modiify the shape, size, position of an element without affecting the normal document flow

types of CSS transformation include:

  • translate()
  • rotate()
  • scale()
  • skew()

Translate: The translate function moves an element from its original position to without affecting the normal document flow.

Rotate: The rotate () funtion rotates an element by a specific angle.

Scale: The scale funtion increases or decreases the size of an element.

skewThe skew() funtion distorts an element by tilting along the x or y axis. Tilting simply means slanting it.
