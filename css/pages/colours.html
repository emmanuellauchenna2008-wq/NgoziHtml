CSS Colours and Backgrounds

The rgb() function defines colours using vaules from 0 to 255 for red, green and blue.

RGBA allows colors to be transparent using the alpha channels (values are between 0 and 1). RGBA is simply rgb with transparency.

Hex codes are use a # followed by six characters (numbers 0-9 and letters A-F). Its syntax is #RRGGBB or #RGB(shortcut form)

HSL is another way to define colours based on Hue (0-360), saturation(%), and lightness(%). Its syntax is : hsl (hue, saturation, lightness)

HSLA is similar to HSL but include an alpha value for transparency.
