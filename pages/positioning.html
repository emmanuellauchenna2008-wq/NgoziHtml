CSS positioning

static positioning By default, all elements are positioned statically. This means theyb appear in normal document flow.

relative positioning: An element positioned relative stays in the normal flow but can be shifted using top, right , bottom or left.

absolute positioning: An element positioned absolute is removed from the normal flow . It positions to the nearest positioned ancestor(which is not static)

On absolute positioning

Fixed positioning: A fixed position stays in the same position when scrolling.

sticky positioning:A sticky element acts like relative until a certain scroll position is reached, then it behaves like fixed.
